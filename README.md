# 🎞️ MediaHub — Multimedia Converter

Herramienta de conversión multimedia standalone parte del ecosistema **Media Hub**.
Convierte Audio, Video e Imágenes en modo individual o por lotes con aceleración por GPU.

## Herramientas incluidas
- **Audio Converter**: MP3, WAV, FLAC, OGG, M4A
- **Video Converter**: MP4, MKV, AVI, MOV, WEBM + extracción a MP3
- **Image Converter**: JPG, PNG, WEBP, GIF, BMP, TIFF y más
- **Image Rescaler**: Redimensión por píxeles o porcentaje
- **Audio Cut**: Corte con visualización de waveform, Fade In/Out

## Instalación
\\\powershell
pip install -r requirements.txt
\\\

## Ejecución
\\\powershell
python main.py
\\\

## Requisitos
- Python 3.11+
- FFmpeg instalado en el PATH
- Windows 10/11
